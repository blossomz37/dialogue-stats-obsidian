# Changelog

## 0.1.0 — 2026-09-19

- Status bar: word count and dialogue percentage for the active note.
- Settings tab: live preview, threshold sliders, color pickers, toggle, reset.
- Commands: show stats (mobile fallback), toggle status bar, refresh.
- Counting rules shared with the VS Code extension and `dialogue-ratio.py`.

## 0.1.1 — 2026-09-20

- Settings tab moved to Obsidian's declarative settings API. Settings now appear in Obsidian's settings search. Requires Obsidian 1.13 or later.
- Releases are built and attested by GitHub Actions.
